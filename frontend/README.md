# Frontend WebGIS Banjir

Frontend React, Tailwind CSS, dan React-Leaflet. Dari folder `frontend`, jalankan `npm install` lalu `npm run dev`; Vite tersedia di `http://localhost:5173`.

API default mengarah ke `http://localhost:3000/api`. Untuk alamat lain, buat `.env` dengan `VITE_API_URL=http://alamat-api/api`. Peta dasar menggunakan tile OpenStreetMap dan memerlukan koneksi internet.
